# Outputs

Derived outputs that are safe to publish belong here, such as:

- summary reports
- normalized export tables
- NDEx-ready network artifacts
- literature scouting summaries
- corpus count tables

Current structure:

- `reports/literature/`
  Collection-level scouting summaries and count tables.
- `reports/fulltext/`
  Full-text relevance review outputs.
- `reports/core/`
  Structured outputs derived from the current `215 relevant` paper core.
