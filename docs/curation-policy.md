# Curation Policy

## Paper records

Each paper record should preserve:

- identifier metadata
- center and PI attribution
- pathogen/virus tags
- assay/data type tags
- dataset/resource extraction status

## Dataset/resource records

Each dataset/resource record should preserve:

- source paper
- accessions and URLs
- host/pathogen context
- assay type
- reuse assessment
- access friction notes

## Derived interpretations

Derived pathway or convergence claims should be kept separate from source metadata and marked clearly as derived outputs.
