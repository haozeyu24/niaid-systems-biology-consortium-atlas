# PI Backlog

This folder holds the broader PI-history scouting layer.

It is intentionally noisy compared with the official program and HPMI layers because it is meant to capture:

- historical work from relevant PIs and labs
- papers outside the narrow current grant-query corpus
- possible mechanistic or dataset-rich papers worth pulling into the consortium workflow

Key files:

- `manifest.csv`
  Flat paper-level PI-backlog inventory.
- `review-queue.csv`
  First-pass title+abstract triage surface for include/watch/exclude logic.
- `records/`
  One normalized metadata record per paper.
