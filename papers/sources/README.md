# Sources

This folder groups literature by how it entered the atlas.

Subfolders:

- `current-program/`
  Official current Systems Biology for Infectious Diseases grant-query corpus.
- `hpmi/`
  Explicit HPMI literature layer.
- `pi-backlog/`
  Broader PI-history scouting layer.

These are the collection routes. They are the starting point, not the final working corpus.
