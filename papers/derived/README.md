# Derived

This folder groups literature layers that are derived from the source collections.

Subfolders:

- `full-collection/`
  PMID-level union across collection routes.
- `consortium-subset/`
  Heuristic candidate corpus promoted from the broader union.
- `relevance/`
  Full-text relevance review and structured extraction over the current mechanistic core.

These folders are the main working outputs for downstream analysis.
