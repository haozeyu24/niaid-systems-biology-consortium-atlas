# Relevance

This folder holds the second-pass full-text review outputs.

Key files:

- `fulltext-selection.csv`
  Full-text review sheet for the `654` candidate papers with `relevant`, `maybe`, and `not_relevant` decisions.
- `relevant-paper-core.csv`
  Structured extraction layer for the `215 relevant` papers, including virus labels, host systems, assays, dataset signals, and priority buckets.

This is the current best entry point for the scientifically useful paper core.
