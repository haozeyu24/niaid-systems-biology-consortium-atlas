# Full Collection

This folder holds the merged literature view across:

- `current-program`
- `hpmi`
- `pi-backlog`

`manifest.csv` is a PMID-level union view intended to answer:

- how many distinct papers are in the atlas overall
- which papers appear in more than one collection route
- what center and PI candidate metadata are attached to each paper

This is the broadest literature manifest in the repo.
